# 서울 옥상 지도 (Seoul Rooftop Map) 🏙️

서울 시내에서 시민에게 무료 또는 자유롭게 개방되어 있는 옥상정원, 루프탑 테라스, 전망대 39곳을 한눈에 찾아볼 수 있는 인터랙티브 지도 웹 애플리케이션입니다.

## 📌 주요 기능

- **🗺️ Leaflet 인터랙티브 지도**: 서울 전역의 개방 옥상 위치를 맞춤형 핀 아이콘(🌿 정원, ☕ 카페, 🌙 야간개방, 🌆 전망, 🏢 빌딩)으로 시각화
- **🔍 스마트 검색 및 실시간 필터링**:
  - 명소 이름, 도로명/구/동 주소, 뷰 키워드(예: `경복궁`, `남산`, `한강`, `노을`, `비행기` 등) 검색 지원
  - 카테고리 필터: `전체`, `🌿 정원`, `☕ 카페`, `🌙 야간개방`, `🆓 무료`, `🚪 개방형`
- **📊 상세 정보 패널**:
  - 정확한 층수 및 건물 높이
  - 개방 시간 및 휴관일 안내
  - 입장료 및 외부인 출입 허용 여부
  - 파노라마 조망 및 현장 특징 설명
  - 방문자 리뷰 및 팁
- **📍 새 옥상 제보하기**: 시민들이 알고 있는 숨은 개방 옥상을 직접 등록 및 제보할 수 있는 모달 폼 제공
